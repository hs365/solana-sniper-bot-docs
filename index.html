核心亮点与特别之处

为什么不只是又一个 sniper？

Q1

这个脚本有什么特别之处？为什么要用它？

  • 双重极速扫描：采用全新的底层 TLS 伪装技术，直接穿透 Cloudflare 防护，秒级抓取最新上线的潜力代币。
  • 全自动追踪监控：买入后，机器人会启动独立线程，每 5 秒在链上询价，比肉眼看 K 线快百倍。
  • 双模一键切换：支持"模拟盘（Dry Run）"和"实盘"一键切换。在不花真钱的情况下，也能带你完整体验抢盘、扣税、出局的真实战场。
Q2

听闻土狗盘骗局极多，这台机器人如何防 RUG（跑路）？

它内置了一套极其强悍的 【智能合约黑心权限风控雷达】：

  • 放弃增发/冻结：自动检测项目方是否丢弃了 Mint 和 Freeze 权限，有增发或冻结直接枪毙，防貔貅盘。
  • 前 10 大户与老鼠仓过滤：前 10 大地址持币占比过高、内部人员（Dev 团队）持仓过高的盘子一律不碰。
  • 池子锁定检查：普通盘流动性池（LP）未锁定或锁仓比例低于 80% 的直接过滤。
Q3

它的自定义功能多吗？我能调整哪些策略？

非常丰富！所有核心参数都集中在代码顶部的 CONF 字典中，你可以自由调整：

  • 资金控制：自定义单笔投入（INVEST_SOL）和钱包安全留存底线（MIN_RESERVE_SOL）。
  • 滑点控制：买入/卖出滑点独立配置，支持卖出失败时自动放大滑点的"逃生通道"。
  • 5 重出局策略：
    • 静态止盈（默认涨 50% 自动分批回本）
    • 静态止损（如跌 15% 果断割肉）
    • 移动追踪止损（最高点回撤 20% 保护利润出局）
    • 保本逃生（涨过 10% 后如果跌回 2% 成本线，强制保本平仓）
    • 超时强制平仓（超过 8 分钟不管输赢强制砸盘，防归零）

新手上路与环境配置

从 0 到运行，5 分钟搞定

Q4

第一次拿到脚本，我的电脑/服务器需要安装什么？

本机器人基于 Python 3.10+ 开发。请先确保你安装了 Python，然后打开终端（Terminal 或 CMD）运行以下命令，一键安装所有依赖库：

bash 
pip install asyncio aiohttp solders solana colorama python-dotenv curl_cffi requests
Q5

如何配置我的钱包和节点（.env 文件）？

在脚本同级目录下，新建一个名为 .env 的文本文件（注意前面有一个点），里面填入以下内容：

ini / toml 
# 你的 Solana 钱包私钥 (Base58 格式，去 Phantom 或 Solflare 钱包导出)
SOL_PRIVATE_KEY=你的真实私钥

# 你的高级 RPC 节点地址 (强烈建议去 Helius 或 QuickNode 申请免费/付费专属节点，不要用公共节点)
RPC_URLS=https://mainnet.helius-rpc.com/?api-key=你的Key

# Telegram 通知配置（可选）
TG_BOT_TOKEN=你的TG机器人Token
TG_CHAT_ID=你的TG群或频道ID

# API 密钥配置（可选，有的话速度更快）
JUPITER_API_KEY=你的JUPAPIKEY
⚠️
安全警告：私钥等于你的钱包控制权，.env 文件切勿上传到 GitHub、截图发群、分享给任何人。建议使用专门用于跑机器人的"热钱包"。
Q6

配置好了，怎么启动运行？

打开终端，切换到脚本所在目录，执行以下命令即可：

bash 
python sol_8.py
💡
建议用 tmux / screen / nohup 在服务器后台跑，关掉 SSH 也不会断。

Q7

为什么机器人一直在扫描，显示"获取到 27 个最新代币"，却一单都不开？

正常蹲守现象：脚本运行后会把第一次扫到的 27 个老代币记录到黑名单，防止重复买入。由于 Solana 链上不是每秒都在发高质量新盘子，当市场没有新面孔出现时，机器人会选择保持静默。请耐心挂着，一旦有新代币诞生并符合风控，它会秒级冲锋！

风控门槛过高：请检查你的 CONF 里的风控参数。例如开盘年龄、最小流动性（RISK_MIN_LIQ_USD）、持币人数等，如果设置太严，机器人会把所有新币都过滤掉。

Q8

日志提示"钱包扫描失败"是什么原因？

  • 节点限制：这说明你的 RPC 节点在查询链上余额时超时或被限流了。请在 .env 中更换更稳定的第三方节点（如 Helius 节点）。
  • 模拟盘无影响：如果你处于 DRY_RUN: True 模拟盘状态，钱包扫描失败不影响你正常接收扫描信号和模拟交易，可以无视。
Q9

我想玩真钱，怎么切到实盘交易？

非常简单，只需要修改代码配置区（大概第 112 行）的一个开关：

  • 模拟盘（默认）："DRY_RUN": True（只打日志、模拟发 TG，不花真钱，自带 1% 模拟损耗）。
  • 实盘交易："DRY_RUN": False（真刀真枪，直接调用 Jupiter 消耗钱包里的 SOL 上链交互）。
⚠️
实盘警告：首次切到实盘，请务必将 INVEST_SOL 改小（如 0.01），确认买卖流程无误后，再放大资金！
Q10

机器人重启了，它会忘记之前买过的币或者漏掉正在监控的币吗？

不会，它有完美的 "记忆恢复机制"：

  • 机器人每次买卖都会记录在 trade_history.csv 账本里，开机时会自动读取，绝不吃回头草。
  • 未平仓的币会保存在 active_positions.json 缓存文件中，重启后脚本会自动无缝恢复监控，接管你的资产。
💡
小提示：土狗市场瞬息万变，建议先在 DRY_RUN: True 模式下挂机运行 1~2 天，熟悉机器人的出局逻辑与 TG 播报后，再考虑小资金切入实盘。DYOR！
